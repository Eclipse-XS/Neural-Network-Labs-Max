## 2. Послідовність виконання блокнотів та залежності

Виконання дослідження відбувається за чітким конвеєром:

1. **`01_input_images_and_pipeline.ipynb`** (Етап 1):
   - Проводить аудит 3 оригінальних зображень у каталозі `inputs/` (перевірка розмірів $512 \times 512$, колірного простору RGB, формату PNG).
   - Здійснює діагностику CUDA-пристрою (NVIDIA GeForce RTX 3050 Laptop GPU, 4 ГБ VRAM).
   - Завантажує `stable-diffusion-v1-5/stable-diffusion-v1-5` у половинній точності FP16 з активацією `pipe.enable_model_cpu_offload()` для запобігання помилкам переповнення відеопам'яті (OOM).
   - Генерує базові зображення (baseline) для 3 сюжетів та записує їх у `outputs/images/baseline/` разом із детальними JSON-метаданими в `outputs/metadata/`.

2. **`02_parameter_experiments.ipynb`** (Етап 2):
   - Завантажує базове зображення `01_coastal_lighthouse.png` та фіксує єдиний промпт.
   - Проводить контрольовані параметричні розгортки при строго фіксованому генераторі випадкових чисел (`seed=42`):
     - **Strength:** $0.3 / 0.6 / 0.9$ (дослідження збереження вихідної геометрії vs творчої модифікації);
     - **CFG (Guidance Scale):** $5.0 / 7.5 / 10.0$ (вплив сили спрямування текстового ембеддингу);
     - **Inference Steps:** $20 / 30 / 50$ (компроміс між деталізацією та обчислювальним часом);
     - **Negative Prompt:** порівняння генерації з увімкненим та вимкненим негативним промптом.
   - Зберігає результати у відповідні підкаталоги `outputs/images/` та фіксує єдиний реєстр `outputs/tables/generations_registry.csv`.

3. **`03_results_analysis.ipynb`** (Етап 3):
   - Завантажує збережені артефакти та формує наочні зіставні сітки (side-by-side comparison grids).
   - Проводить кількісний аналіз латентності інференсу, швидкості генерації (it/s) та використання VRAM на RTX 3050.
   - Аналізує математичний апарат Low-Rank Adaptation (LoRA) для адаптації дифузійних моделей при обмежених ресурсах пам'яті.

**CWD-незалежність та розмежування режимів:** Усі блокноти динамічно знаходять свій каталог `LAB_DIR = resolve_lab_dir()`. Вони підтримують прозоре інспектування верифікованих історичних результатів з можливістю повторного запуску генерації на GPU без презентації кешованих даних під виглядом нових.
