## 2. Відповідність вимогам Варіанта №2

1. **Мультимодальна модель LLaVA:**  
   Використано офіційну модель родини LLaVA — `llava-hf/llava-interleave-qwen-0.5b-hf`, що поєднує зоровий енкодер SigLIP, MLP-проектор та мовну основу Qwen2. Модель розгорнуто в половинній точності FP16 на графічному процесорі NVIDIA GeForce RTX 3050 Laptop GPU, споживаючи менше 2.0 ГБ VRAM.

2. **Набір вхідних зображень:**  
   Використано 4 візуально та семантично різнорідні зображення: маяк на скелі, міське кафе з велосипедом, інтер'єр старовинної бібліотеки та сучасна наукова лабораторія робототехніки.

3. **Дослідження впливу формулювання промпту (Prompt Wording):**  
   - *Concise:* забезпечує миттєву ідентифікацію семантичного ядра (11–12 токенів, 0.8 с);
   - *Descriptive:* формує зв'язний структурований абзац (100–128 токенів, ~6.5–7.5 с);
   - *Detailed:* вичерпно описує просторові відношення, освітлення та текстури.

4. **Дослідження впливу `temperature` ($0.0 \to 0.2 \to 0.7 \to 1.0$):**  
   - $T=0.0$: максимальна детермінованість та фактологічна точність;
   - $T=0.7$: збагачення словника та поява образних зворотів («serene backdrop», «stylized representation»);
   - $T=1.0$: зростання стохастичності та ентропії тексту.

5. **Дослідження бюджету токенів (`max_new_tokens` $\in [32, 64, 128, 256]$):**  
   - 32/64: передчасне синтаксичне обривання речень;
   - 128: збалансований опис;
   - 256: природне завершення генерації токеном `<|im_end|>` на 208 токенах для складного технічного зображення без зациклення.

6. **Якісна оцінка заземленості та відсутності галюцинацій:**  
   Покриття ключових візуальних сутностей становить 85–95% для досліджених сцен. У детермінованому режимі ($T=0.0$) модель коректно перераховує основні видимі об'єкти без внесення вигаданих деталей у межах тестового набору.
