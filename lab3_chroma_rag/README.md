## 2. Швидкий запуск

### Вимоги:
- Python 3.12+ у віртуальному оточенні (`.venv-lab04`);
- Локальний OpenAI-сумісний сервер: клієнт із ЛР2 за замовчуванням орієнтований на vLLM (`http://127.0.0.1:8000/v1`, модель `Qwen/Qwen2.5-1.5B-Instruct-AWQ`), а за його відсутності підтримує задокументований fallback на локальну службу Ollama (`http://127.0.0.1:11434/v1` з моделлю `qwen3:4b-instruct`).

### Запуск тестів:
```powershell
pytest lab3_chroma_rag/tests/test_lab03.py -v
```

### Запуск ноутбуків у Jupyter:
```powershell
jupyter lab
```

## 3. Ключові результати
1. **База знань:** 8 документів, 23 884 символи (2 936 слів), 0 порожніх файлів, 0 дублікатів (6 `.md`, 2 `.txt`).
2. **Чанкінг:** конфігурація `chunk_size=700`, `chunk_overlap=100` утворила 55 фрагментів (середня довжина 434.8 символів) із збереженням метаданих `source`, `type`, `chunk_id`, `document_id`.
3. **ChromaDB:** персистентне сховище на ембеддингах `sentence-transformers/all-MiniLM-L6-v2` ($d=384$, колекція `nnts_variant2_kb`, 55 векторів; метрика простору $L_2$, ранжування за якою строго монотонно еквівалентне косинусному для нормалізованих векторів: $\|a-b\|_2^2 = 2 - 2\cos(a,b)$).
4. **Similarity vs MMR:** MMR підвищує різноманітність джерел на багатоаспектних запитах, зменшуючи надлишкову концентрацію на одному документі, водночас для вузьких фактів видачі збігаються.
5. **Фільтри метаданих:** підтверджено повну ізоляцію простору пошуку за `type="md"`, `type="txt"` та за конкретним файлом джерела.
6. **Локальна LLM:** згенеровано 18 відповідей (9 Similarity, 9 MMR). Підтверджено заземленість у наданий контекст із цитуванням джерел; у контрольному out-of-domain запиті Q9 модель коректно відмовилася відповідати за відсутності інформації в базі знань.
